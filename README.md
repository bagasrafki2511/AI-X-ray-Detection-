## X-ray AI Detection System

Aplikasi AI berbasis CNN (EfficientNetV2-S) untuk mendeteksi indikasi penyakit dari citra X-ray.
Dilengkapi dengan Grad-CAM untuk visualisasi area penting.

### Teknologi
- Python
- PyTorch
- Streamlit
- EfficientNetV2-S

### Cara Menjalankan
```bash
pip install -r requirements.txt
streamlit run app.py
